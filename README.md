<h2><a class="anchor" id="overview"></a>Overview</h2>

StreamVerse OTT Platform Analytics is a comprehensive Business Intelligence and Customer Churn Analysis project designed to transform large-scale streaming data into meaningful business insights. The project simulates a real-world OTT ecosystem by integrating data from multiple operational domains, including subscribers, content, viewing history, subscription plans, payments, ratings, device usage, recommendation systems, and playback quality.

A relational database was designed using SQL to store, manage, and analyze more than 13.5 million streaming records across multiple interconnected tables. Python was used for data cleaning, preprocessing, feature engineering, and exploratory data analysis to ensure data quality and extract meaningful patterns.

Interactive dashboards were developed in Power BI to monitor critical business metrics, including subscriber growth, customer churn, viewer engagement, content performance, revenue generation, recommendation effectiveness, and streaming quality. The dashboards enabled drill-down analysis and provided stakeholders with a centralized platform for monitoring key performance indicators.

The project focused on identifying the factors that influence customer retention and content consumption while uncovering trends in user behavior across different subscription plans, devices, and content categories. The analytical findings generated actionable recommendations that can help OTT platforms optimize content strategies, improve customer experience, reduce subscriber churn, and maximize revenue.

# Project Workflow

Raw Data → SQL → Data Cleaning → Feature Engineering →
Power BI Dashboard → Business Insights

# Key Responsibilities

- Designed and implemented a relational database for OTT streaming data.
- Performed data extraction, cleaning, transformation, and validation using Python and SQL.
- Applied feature engineering techniques to create analytical variables for customer and content analysis.
- Conducted exploratory data analysis to identify patterns and trends in subscriber behavior.
- Developed interactive Power BI dashboards for business performance monitoring.
- Analyzed customer churn, engagement, revenue, recommendation effectiveness, and content performance.
- Generated business insights and strategic recommendations based on analytical findings.
